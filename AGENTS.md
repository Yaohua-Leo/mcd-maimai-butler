# Project instructions

- This repository is a McDonald's MCP innovation challenge project.
- Keep `MCD_MCP_TOKEN` outside Git and outside all documentation, logs, screenshots, and prompts.
- Use the project-scoped MCP configuration in `.codex/config.toml`. Keep the default MCP approval mode as `prompt`.
- Treat `create-order`, `cancel-order`, coupon binding, lottery draw, points redemption, and other state-changing tools as requiring explicit user approval for each call.
- Record the actual tools and call flow used by the final Skill in `MCP_INTEGRATION.md`; label untested items as planned.
- Keep `CONTEST_DECLARATION.md` unchanged from the official contest repository.
- Do not submit or publish the repository until the required files, source code, public access, and secret scan have been reviewed.
